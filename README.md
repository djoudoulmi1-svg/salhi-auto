# Salhi Auto

موقع Salhi Auto مبني على Next.js وTailwind CSS، مع إعداد أولي لقاعدة Supabase.

## التشغيل

1. ثبّت Node.js 20 أو أحدث.
2. نفّذ `npm install` ثم `npm run dev`.
3. افتح `http://localhost:3000`.

## تسجيل دخول المالك والموظفين

1. أنشئ مشروع Supabase مخصصاً لـ Salhi Auto، ولا تستخدم قاعدة بيانات مشروع آخر.
2. انسخ `.env.example` إلى `.env.local` وأضف رابط المشروع والمفتاح العام ومفتاح الخادم السري. لا تضع المفتاح السري في متغير يبدأ بـ `NEXT_PUBLIC_`.
3. طبّق `supabase/migrations/0001_initial.sql` من محرر SQL في مشروع Salhi Auto.
4. عيّن قيمة سرية طويلة لـ `SALHI_SETUP_TOKEN` ثم أعد تشغيل الموقع.
5. افتح `/admin/setup` وأنشئ اسم مستخدم وكلمة مرور المالك. اسم المستخدم وكلمة المرور يختارهما المالك؛ لا نطلب بريداً حقيقياً ولا نرسل رسائل بريدية.
6. بعد الدخول، افتح `/admin/staff` لإضافة حسابات الموظفين والمديرين، إيقافها أو تغيير كلمات مرورها.

تُنشأ حسابات Supabase خلفياً ببريد داخلي غير قابل للاستلام (`.invalid`) لأن Supabase Auth يتطلب معرّف بريد داخلياً. لا يُعرض هذا البريد للموظف ولا تُرسل إليه رسائل. كلمة المرور يحفظها Supabase Auth بصورة مشفّرة؛ لا يحفظها التطبيق في قاعدة البيانات.

## الحالة

- الصفحة الرئيسية ولوحة الإدارة واجهتان أوليتان.
- السيارات والأرقام في لوحة الإدارة توضيحية وليست بيانات المعرض.
- تسجيل الدخول باسم المستخدم، إعداد المالك لمرة واحدة، وإدارة حسابات الفريق جاهزة بعد تهيئة مشروع Salhi Auto وتطبيق المخطط.
- مخزون السيارات والأرقام في لوحة الإدارة ما زالت تجريبية؛ لم يتم ربطها بقاعدة البيانات بعد.
- بيانات الهاتف وWhatsApp الفعلية، شعار المعرض، مفاتيح Supabase وإعداد Vercel مطلوبة قبل الإطلاق.
